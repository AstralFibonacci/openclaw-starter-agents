## Ticket Structure

Standard ticket fields:

| Field | Description |
|-------|-------------|
| ID | Unique ticket number |
| Customer | Who reported |
| Subject | Issue summary |
| Category | Type of issue |
| Status | Open / Pending / Resolved |
| Priority | Low / Medium / High |

---

## Response Templates

### FAQ Response
```markdown
Hi [Name],

Thanks for reaching out!

[Answer to their question]

If you have any other questions, feel free to ask!

[Your Name]
Support Team
```

### Need More Info
```markdown
Hi [Name],

To help you better, could you please provide:

- [Specific info needed]

Once I have this, I'll be able to assist you quickly!

[Your Name]
```

### Escalation
```markdown
Hi [Name],

I've escalated your ticket to our team. They'll reach out within [timeframe].

Your ticket reference: [ID]

Thanks for your patience!

[Your Name]
```

## Common Issues & Solutions

| Issue | Solution |
|-------|-----------|
| Can't login | Password reset link |
| Billing question | Escalate to billing |
| Feature not working | Gather details, escalate |
| Refund request | Escalate to billing |
| Account update | Verify identity first |

---

## Priority Handling

| Priority | Response Time |
|----------|---------------|
| High | 1 hour |
| Medium | 4 hours |
| Low | 24 hours |

---

## Escalation Criteria

Escalate when:
- Billing/refund requests
- Security concerns
- Technical issues beyond FAQ
- Customer requests human
- 3+ responses without resolution
